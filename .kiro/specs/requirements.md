# 需求规格说明书 (Requirements) - 代码风水罗盘

## 1. 用户故事与验收标准

### US-01: 代码输入与样本载入
- **Given** 用户打开风水罗盘工作台；
- **When** 点击顶部《window.god 全局祖传邪神》或《零崩溃静默吞异常》等样本；
- **Then** 编辑器实时载入对应代码，并自动触发一次完整堪舆计算。

### US-02: 真实 AST 风水神煞检出
- **Given** 输入包含多重嵌套与全局 window 污染的代码；
- **When** 触发堪舆；
- **Then** 服务端必须通过原生 AST / 词法分析定位行号、计算圈复杂度，绝不能硬编码静态随机数。

### US-03: 罗盘指针物理动态
- **Given** 堪舆结果煞气值 >= 70；
- **When** 前端接收到结果；
- **Then** 天池磁针旋转至对应凶位角度（180度），并开启高频微幅颤针动效（`quiver`），状态文字提示“⚠️ 阴气暴涨·天池针颤”。

### US-04: 一键化煞与镇宅符导出
- **Given** 代码处于大凶状态；
- **When** 用户点击【请神重构·一键化煞】；
- **Then** 编辑器代码平滑重写为化煞闭包代码，播放雷霆法钟音效，增加功德数值，罗盘归向大吉方位；
- **When** 点击【迎请镇宅符】；
- **Then** 弹出高清传统朱砂镇宅符模态框，提供一键复制 Markdown 文本到剪贴板。
