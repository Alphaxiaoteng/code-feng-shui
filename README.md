## 🌟 核心创意亮点 (Why It's Boring But Fun)
1. **真实 AST 词法底座**: 绝非静态 Mock，基于真实圈复杂度、深渊嵌套、死锁互斥与并发忙等检测；
2. **东方神煞风水体系**:
   - `祖坟冒黑烟`: 全局 `window.xxx` 暴力污染与无界定时器暴食；
   - `九阴穿心煞`: 深度回调地狱与 4 重以上死循环嵌套；
   - `掩耳盗铃棺`: 空 catch 吞噬银行接口超时异常返回 null；
   - `困龙绝命阵`: 资源抢锁顺序倒置且未设置 Context 抢锁超时的并发死局；
   - `破财败运星`: 前端明文硬编码生产环境 AWS 私钥与 SQL 字符拼接。
3. **道藏册府 · 8 大真实工业案卷锦匣画廊**:
   - 包含《除夕挤兑·双花阴煞案》、《万行巨石·邪神内存黑洞》、《九重深渊·同步阻塞爬虫录》、《天机泄露·破财明密折》、《困龙绝命·并发死锁阵》、《狂风卷叶·万级递归爆栈篇》、《死盖暗棺·全链路静默黑洞》、《紫气东来·现代纯阳服务》；
   - 纯手绘矢量 SVG 专属图腾徽标（零系统 Emoji），配备天机题拔照壁联动展开事故案由。
4. **巨幅 380px 东方道藏八卦同心罗盘**: 外方内圆、二十四山同心盘、天池水银磁针（检出凶煞时高频剧烈偏颤！）；
5. **一键请神重构·化煞安魂**: 一键将屎山重构为现代高内聚纯阳版本，支持双栏 Diff 审阅；
6. **正一天师·2K 宣纸镇宅神符与 PR 战报**: 自动生成古典黄色朱砂符纸壁纸（可下载 PNG）与 Markdown 战报，可直接贴在 GitHub PR 或服务器机箱上镇压 Bug！

## 🏗️ Kiro 技术深度结合体系 (Kiro-Native Architecture)

本项目严格贯彻 Kiro 原生开发哲学：
- **Kiro Spec 驱动开发 (`.kiro/specs/`)**:
  - `requirements.md`: 形式化定义神煞检测边界、输入经案规范与风水五行映射模型；
  - `design.md`: 架构决策拆解为三幕殿堂分场景（投喂经卷 -> 动盘堪舆 -> 请神化煞）、水银天池渲染引擎与 AST 静态堪舆网关；
  - `tasks.md`: 将多 Agent 开发任务原子化，涵盖算法、矢量图形与交互状态机。
- **Kiro Crew 多 Agent 协作工坊**:
  - `Daoist-Ast-Agent`: 负责 Python AST 语法树解析与神煞特征定级；
  - `Luopan-Canvas-Agent`: 负责 360° 精密刻度盘数学计算与天针阻尼颤动动效；
  - `Altar-Design-Agent`: 负责云雷夔龙角花、朱砂印章、墨玉锦匣的东方玄学道藏美学把控；
  - `Talisman-Generator-Agent`: 负责 2K 故宫宣纸神符离屏 Canvas 渲染与 PR 战报生成。
- **Agent Hooks 自动化进化**:
  - 联动代码输入与文件拖拽，自动触发堪舆探针，并为重构代码生成契约级单元测试。


```bash
python3 -m pytest test_fengshui_ast.py
```
